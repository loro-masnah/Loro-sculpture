# GitHub collaborator guide
**Repository:** https://github.com/loro-masnah/Loro-sculpture

Documents and configurations are version controlled here. The current repository is **public** as of initial setup. Avoid uploading restricted knowledge archives or unpublished content. Review Settings → General → Danger Zone if you want to make the repository private.

## Contributor workflow
1. Create a short branch for each feature or hardware documentation change.
2. Commit focused changes with descriptive messages.
3. Open a pull request for review before merging significant code changes.
4. Use Issues for week-by-week hardware and software tasks.
5. Attach photographs only with permission; never commit visitor images.
6. Update BOM, setup notes, architecture and acceptance tests as real-world details change.

## Do not upload
- API keys, SSH keys, passwords or local `.env`.
- Unlicensed whole books/transcripts or confidential artistic source material.
- Visitor image recordings or large model weights without careful review.

Starter content is a planning package, not a working AI application.
