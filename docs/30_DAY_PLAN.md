# 30-day execution plan — one parrot
The schedule assumes art fabrication and technical development can progress in parallel. It is a target, not a guarantee.

| Week | Hardware / sculpture | Software / personality | Milestone |
|---|---|---|---|
| 1, days 1–7 | Confirm RAM and accessories; flash microSD; connect camera, HAT and speaker | Verify boot, capture, audio and remote access | Camera takes photo and speaker says test phrase |
| 2, days 8–14 | Test speaker position and cooling | Vision description, retrieval, Philosopher persona, cloud generation, speech and cooldown | Observed object leads to relevant spoken interpretation |
| 3, days 15–21 | Build recycled body, install and secure electronics; optional beak mechanism | Tune voice, response length, retries, logging and boot service | Integrated parrot demonstration |
| 4, days 22–30 | Finish body and service access, install safely | Run 2–4 hour continuous tests; recover from restart/network failures | Exhibition-ready handover |

## Critical checkpoint
By day 7 the Pi should capture a camera image and output intelligible audio. If the BrainCraft HAT codec setup is blocked, evaluate a compatible USB audio fallback and document the decision.

## Definition of done
- Operates unattended from power-on.
- Recognizes common objects without invented visual claims.
- Applies curated worldview material and produces original short statements.
- Speech is understandable at 1–2 meters in intended room.
- Handles network failures without crashing or storing visitor imagery.
